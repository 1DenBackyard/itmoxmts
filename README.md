# Прожарка документации · HTML-прототип

Клиентский прототип ревью ТЗ объектов данных (МТС).  
Без бэкенда и без Streamlit — только браузер.

## Быстрый старт

```bash
cd web
python3 -m http.server 8080
```

Открыть: **http://127.0.0.1:8080**

> Нужен именно локальный сервер: браузер загружает JSON из `web/data/`.

## Что умеет

1. **Старт** — выбрать тип ТЗ (потоки / источник / витрина) и способ:
   - создать с нуля по шаблону;
   - подгрузить своё ТЗ (**PDF**, таблицы распознаются).
2. При загрузке PDF — фильтр серьёзности замечаний: Rare / Medium / Well Done.
3. **Ревью** — документ слева, замечания справа (как в Word):
   - лупа «найти в тексте»;
   - **ИИсправь** → превью правки → применить;
   - Исправлено / Отклонить;
   - прогресс-бар по правкам;
   - редактирование текста и перепроверка.
4. **Итог** — сводка + скачать PDF / текст.
5. **Мой прогресс** — самообучение аналитика на демо-данных:
   - повторяющиеся ошибки, разбор в панели, личный чек-лист.

## Структура репозитория

```
web/                 ← приложение (открывать отсюда)
  index.html
  css/               стили МТС
  js/                логика UI, PDF, ревью, прогресс
  data/              dataset.json + learning.json
  vendor/            pdf.js
  assets/            логотип
ДатасетТЗ/           исходные PDF-примеры
ТЗ_прототип_Streamlit.md   продуктовое ТЗ (описание)
mts_logo_cmyk.png
```

## Полезные кнопки в UI

| Где | Действие |
|-----|----------|
| Шапка | **Мой прогресс** |
| Ревью | Редактировать · Перепроверить · К итогу |
| Замечание | ИИсправь · Исправлено · Отклонить · 🔍 |
| Итог | Скачать PDF · Скачать текст |

## Замечания по прототипу

- Замечания и автоправки — **демо-логика** (правила + датасет), не боевая LLM.
- «Мой прогресс» заполнен **демонстрационными** данными (`web/data/learning.json`).
- PDF на итоге открывает диалог печати → выберите «Сохранить как PDF».
