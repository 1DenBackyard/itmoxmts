# ТЗ: поток заказов интернет-магазина

## Общие сведения

Поток `ORDER_EVENTS` передаёт события заказов из PostgreSQL в Kafka и далее в витрину `DM_ORDERS`.
Заказчик: команда электронной коммерции. Владелец: продуктовая аналитика.

## Режим загрузки

Данные загружаются инкрементально каждые 15 минут. Раз в сутки выполняется полная перезагрузка текущего месяца. Повторный запуск создаёт новые записи.

## Источник и приёмник

| Объект | Значение | Формат |
| source | orders.public.orders | PostgreSQL |
| target | dm_sales.dm_orders | Parquet |
| topic | ORDER_EVENTS | JSON |

## Структура данных

| Поле | Тип | Обязательность | Источник | Правило расчёта |
| order_id | string | NOT NULL | orders.id | прямое отображение |
| customer_id | string | NULL | orders.customer_id | прямое отображение |
| amount | decimal(12,2) | NOT NULL | orders.amount | сумма заказа |
| status | string | NOT NULL | orders.status | справочник статусов не указан |
| event_time | timestamp | NOT NULL | orders.updated_at | часовой пояс не указан |

## Требования

Данные должны быть доступны без задержки. Хранить историю 90 дней. Доступность — 99,9%. Политика обработки удалённых заказов и late events не определена.
