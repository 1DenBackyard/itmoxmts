# ТЗ: витрина качества радиосети

## Общие сведения

Витрина агрегирует показатели качества радиосети по регионам и часовым интервалам. Обновление — каждый час, готовность данных — до 08:00 МСК следующего дня.

## Источники данных

| Источник | Объект | Частота | Ключ |
| Radio Events | KAFKA_CLUSTER / RADIO_EVENTS | потоковая | subscriber_id |
| География | GEO.REGIONS | ежедневно | region_code |
| Оборудование | INVENTORY.CELLS | еженедельно | cell_id |

## Алгоритм

События принимаются за последние 24 часа, дубликаты удаляются, затем рассчитываются показатели по региону. Для неизвестного `region_code` запись отбрасывается. Ниже указано, что неизвестный регион должен сохраняться со значением `UNKNOWN`.

## Структура витрины

| Поле | Тип | NULL | Описание |
| report_hour | timestamp | NOT NULL | начало часа, часовой пояс UTC |
| region_code | varchar(20) | NOT NULL | код региона |
| active_users | bigint | NOT NULL | уникальные абоненты |
| avg_signal | decimal(5,2) | NULL | средний уровень сигнала |
| quality_score | decimal(5,2) | NULL | формула не указана |

## Нефункциональные требования

Объём входа — от 5 до 70 млн событий в сутки. SLA восстановления после сбоя, допустимая доля потерь и правила перерасчёта прошлых периодов не определены. Срок хранения одновременно указан как 3 года и бессрочно.
