# ТЗ: контракт потока платежей

## Назначение

Передавать подтверждённые платежи из биллинга в аналитическую платформу для финансовой отчётности.

## Контракт Kafka

| Параметр | Значение |
| Топик | BILLING_PAYMENTS |
| Формат | Avro |
| Партиций | 12 |
| Репликация | 3 |
| Ключ | payment_id |

## Поля сообщения

| Поле | Тип | Обязательное | Описание |
| payment_id | string | да | идентификатор платежа |
| subscriber_id | string | да | идентификатор абонента |
| amount | double | да | сумма |
| currency | string | нет | код валюты |
| paid_at | string | да | время оплаты |

## Обработка

Получатель обязан обработать сообщение ровно один раз. При ошибке сообщение повторяется. Максимальное число повторов, DLQ, схема идемпотентности и версия Avro-схемы не указаны.

Отрицательная сумма считается возвратом. В другом разделе возвраты запрещены. Персональные идентификаторы должны храниться в открытом виде для отладки; требования по маскированию и сроку хранения отсутствуют.
