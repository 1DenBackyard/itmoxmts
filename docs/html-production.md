# Production: HTML/CSS + FastAPI

Обновление: замечания имеют постоянные номера внутри ревью. Точные цитаты подсвечиваются
в документе и связываются с карточками через кликабельные индексы. Фильтрация номера
не меняет. Для повторяющихся цитат отмечено первое совпадение; отсутствующая цитата
явно помечается как не имеющая точной привязки. Таблицы сохраняют структуру.
Первичный провайдер анализа теперь DeepSeek при наличии ключа, Cloud.ru FM — резерв.

Оформление взято из `prototypes/web-review`. Рабочий frontend — `web/`.
Демонстрационные анализаторы, score и результаты прототипа не загружаются.
Этот документ заменяет описание предыдущей версии `production-ui.md`.

Сохранены вход существующими аккаунтами, PDF/DOCX/TXT/Markdown и вставка текста,
local/S3 storage, четыре агента → критик → судья, GPT-OSS-120B, история и персональные
показатели, решения по замечаниям и их возврат, фильтры, поиск, JSON и чек-лист.
Добавлены редактирование и повторное ревью, текстовый отчёт и печать/PDF браузером.

Новые проверки сохраняют текст и предупреждения. Обновление страницы не прерывает
ожидание задачи. Рестарт сервера помечает незавершённые задачи неудачными: требуется
запуск заново. Недоступная LLM не означает успешное ревью.

## Данные и безопасность

Добавляются только таблицы `web_sessions`, `web_uploads`, `web_jobs`.
Существующие пользователи, результаты и решения не меняются. Старые оригиналы
доступны при наличии объекта в текущем storage. Текст старых вставленных вручную
ТЗ прежде не сохранялся; отчёты по ним остаются доступны.

Сессии — HttpOnly/SameSite cookie на 12 часов, hash токена в БД, Secure на production.
Изменения защищены CSRF; каждый объект проверяется на владельца.
Документы и ответы модели HTML-экранируются. API запускается с одним worker,
двумя рабочими задачами и лимитом четыре задачи суммарно.

## Запуск и деплой

`pip install -e '.[dev]'`, затем `make run` → http://localhost:8501.
Локальная команда отключает Secure cookie только для HTTP localhost.
Production: `uvicorn specguard.web:create_app --factory --host 0.0.0.0 --port 8080 --workers 1`.
GitHub Actions → прежняя Cloud.ru VM. Тома, модель и секреты сохраняются.
Health: `/healthz` и совместимый `/_stcore/health`.
Откат — штатный deploy предыдущей версии; дополнительные таблицы не мешают
прежнему Streamlit. Не удаляйте БД или тома.

## Ограничения

- Фиктивное «ИИ исправь» демо не перенесено: доступны реальные рекомендации и ручные правки.
- Чек-лист — отметки текущей вкладки, не доказательство исправления.
- Персональные ошибки учитываются после принятия/исправления сотрудником.
- Исходный вердикт не переписывается: исправленный текст проверяется заново.
- Просмотр извлечённого текста не является редактором исходного PDF/DOCX.

API-тесты покрывают вход, CSRF, изоляцию, загрузку, фоновые задачи, решения,
сбои и рестарт. JS-тесты проверяют экранирование, таблицы и отсутствие демо-анализа.
