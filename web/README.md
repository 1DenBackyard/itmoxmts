# Веб-прототип «Прожарка документации» (МТС)

Чистый **HTML + CSS + JS** без Streamlit. UI-референс для бэкенда.

## Запуск

Нужен локальный сервер (fetch `data/dataset.json`):

```bash
cd web
python3 -m http.server 8080
```

Откройте: http://127.0.0.1:8080

(Anaconda: `/Applications/anaconda3/bin/python -m http.server 8080`)

## Путь пользователя

1. **Шаблон** — потоки / источник / витрина-агрегат  
2. **Документ** — с нуля, свой файл, или эталон из датасета  
3. **Ревью** — лист документа (с таблицами) + замечания  
4. **Итог** — принято / отклонено / скачать черновик  

На замечании: **✨ ИИ исправь** · **Исправлено** · **Отклонить**  
В шапке: **Редактировать** (прямо в листе) · **Перепроверить** · **К итогу**

## Стек / данные

- `index.html`, `css/mts.css`, `js/*`
- `data/dataset.json` — тексты и предрасчитанные замечания из `ДатасетТЗ/`
- Стилистика: МТС red `#FF0032`, Manrope + Source Serif

Папка `prototype/` (Streamlit) можно не использовать — этот `web/` актуальный UI.
